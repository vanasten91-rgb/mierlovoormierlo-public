# Public snapshot boundary

This repository was created as a clean publication rather than as a mirror.

Included:

- maintained plugin source;
- project-specific theme source;
- portable tests that contain no private release evidence;
- a GitHub-hosted, read-only CI workflow.

Intentionally excluded:

- all earlier Git commits, branches, tags and author metadata;
- internal handoff, live-audit, release, deployment and production-readiness records;
- account inventories and operational role evidence;
- draft audit snippets and redundant packaged source archives;
- environment files, WordPress configuration, database exports, credentials and runtime storage;
- workflows that depend on private or self-hosted infrastructure.

The public commit history begins with the sanitized snapshot only.
